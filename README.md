# Nawigator po Literaturze Andrzeja Sapkowskiego

Interaktywna strona internetowa pozwalająca śledzić chronologię wydarzeń, wątki fabularne oraz dokładne położenie głównych bohaterów (Geralt, Ciri, Yennefer, Triss) w danym momencie historii.

## Funkcjonalności
- **Oś czasu:** Wybór konkretnego wydarzenia i sprawdzenie daty w uniwersum.
- **GPS Bohaterów:** Podgląd, gdzie przebywają poszczególne postacie w trakcie wybranego rozdziału.
- **Baza w JSON:** Łatwe rozbudowywanie danych bez konieczności ingerencji w kod źródłowy JS/HTML.

## Jak uruchomić lokalnie?
Ze względu na wykorzystanie polecenia `fetch()` do wczytywania plików JSON, strona wymaga uruchomienia na lokalnym serwerze (np. rozszerzenie *Live Server* w VS Code lub komenda `python -m http.server`).
